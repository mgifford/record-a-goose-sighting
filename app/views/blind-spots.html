Using this in a review

A clean automated report is not evidence that a page is usable. For each “Not detected” row, the manual checks column names the technique that exposes the problem. The worksheet is a starting point; the answers describe the defects themselves.

This page is about detection, not conformance. Some of these issues are best practice rather than WCAG 2.1 AA failures, and WCAG compliance does not by itself make a service accessible.
