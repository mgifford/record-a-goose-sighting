Text spacing and reflow

Apply increased text spacing and a 320 CSS-pixel viewport. The page should not clip or scroll horizontally. This is a manual rendering test, not an ACT fixture.

A longer passage

Accessibility testing is not a single scan. A page can have a complete heading outline, a valid document language and named controls, and still be difficult to use when text is enlarged, spacing is increased or the viewport is narrow. Read this passage at 200% zoom and again at 320 CSS pixels.

Check that no text is cut off, that words do not overlap, and that controls remain large enough to use. The page may wrap into a single column; that is expected. Horizontal scrolling is the signal to investigate.

  • Line height at least 1.5 times the font size.
  • Paragraph spacing at least twice the font size.
  • Letter spacing at least 0.12 times the font size.
  • Word spacing at least 0.16 times the font size.
